## Отчет по выполнению тестового задания

### Техническое задание
Разработать консольное приложение для управления справочником сотрудников.
1. Создание таблицы сотрудников
2. Добавление нового сотрудника  
3. Вывод уникальных записей по комбинации «ФИО + дата рождения»
4. Автоматическое заполнение (1 000 000 сотрудников + 100 мужчин с ФИО на 'F')
5. Вывод мужчин с ФИО на 'F' и замер времени выполнения
6. Оптимизация производительности пятого режима

### Технологический стек
- **СУБД**: PostgreSQL 17.6
- **Язык программирования**: C++17
- **Компилятор**: g++
- **Система сборки**: Make
- **Библиотека для работы с БД**: libpqxx

### Сборка
```
git clone https://github.com/udult/PTMK_TZ.git
cd ./PTMK_TZ
make install
make 
```

- make - сборка проекта
- make install - установка зависимостей (postgresql, libpqxx)
- make clean - удаление директории сборки 

### Заполнение справочника сотрудников:
Для автоматического заполнения справочника сотрудников использован датасет русских имен (data.csv), 
преобразованный в латинскую транслитерацию с помощью небольшого скрипта convert_dataset.cpp.

ссылка на оригинальный датасет: https://www.kaggle.com/datasets/rai220/russian-cyrillic-names-and-sex?resource=download

### Архитектура
- Класс Employee: представляет данные сотрудника, логику расчета возраста и отправку в базу данных.
- Класс TableManager: управление операциями с БД и пакетной вставкой
- Программа main - запуск пользовательских сценариев

### Оптимизация производительности
В рамках выполнения пункта 6 технического задания требовалось провести оптимизацию базы данных для 
ускорения выполнения запроса пятого режима - выборки сотрудников мужского пола с ФИО, начинающимся на 'F'.

Проведенные работы по оптимизации: создание индекса.
```
CREATE INDEX idx ON employees (fullname, gender) WHERE fullname LIKE '%F' AND gender='male';
```
Обоснование: при сканировании по индексу (при условии что распределение первой буквы имени и пола относительно равномерное) 
будет выгоднее отсечь сначала ~25/26 данных, а уже от оставшихся половину.

для запроса ```SELECT * FROM employees WHERE fullname LIKE 'F%' AND gender='male';``` по таблице с ~2.000.000 записей:

Время выполнения до: ~310ms

Время выполнения после: ~0.030ms
